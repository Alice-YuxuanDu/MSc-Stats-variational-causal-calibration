# Report results

This directory contains only artifacts directly connected to the final report.

- `tables/table1_rff_synthetic/`: synthetic RFF/full-vs-mean-field results in Table 1.
- `tables/table2_rff_ihdp/`: 1,000-realisation IHDP results in Table 2.
- `tables/rff_ihdp_feature_sensitivity/`: the additional feature-number sensitivity described after Table 2.
- `tables/table3_svgp_thresholds/`: threshold diagnostics and summaries reported in Table 3.
- `figure_data/figure1_rff_mf/`: configuration and replication-level input used for Figure 1.
- `figure_data/figure2_svgp_ihdp/`: process, raw-ATE, and corrected-ATE diagnostics plotted in Figure 2.
- `figure_data/figure3_exact_svgp/`: configuration and replication-level input used for Figure 3.
- `config_inputs/lengthscales/`: saved per-replication MAP selections needed by the large synthetic SVGP runs.
- `figures/`: the final PNG and PDF versions of Figures 1--3.

Large diagnostics and unrelated historical runs are intentionally excluded. The root `README.md` maps these artifacts to the final report.
