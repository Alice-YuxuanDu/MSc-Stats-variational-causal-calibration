# Variational Bayesian Posterior Calibration for Semiparametric Causal Inference

Research code and selected reproducibility experiments for the MSc Statistics report by Yuxuan Du.

The experiments compare:

- exact Gaussian-process (GP) inference;
- full-covariance and mean-field (MF) random Fourier feature (RFF) posteriors;
- sparse variational Gaussian processes (SVGPs);
- raw and one-step corrected posterior distributions for the average treatment effect (ATE).

The repository contains the code, tests, exact saved configurations, selected aggregate results, and the data behind Figures 1--3 and Tables 1--3. Large raw experiment directories and the IHDP dataset are intentionally excluded.

## Repository layout

```text
Code/               experiment, analysis, plotting, and test code
data/               IHDP acquisition and checksum instructions
results/figures/    final report figures
results/figure_data data needed to regenerate Figures 1 and 3
results/tables/     report tables, configurations, and threshold diagnostics
```

## Environment

Python 3.11 is recommended.

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Test

Run from the repository root:

```bash
cd Code
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -v
```

The current suite contains 16 unit tests covering the retained experiment and model code.

## Quick synthetic smoke run

```bash
python Code/run_module4_experiment_grid.py \
  --run-name smoke \
  --reps 2 \
  --draws 200 \
  --n-rff-grid 50 \
  --pi-clip-grid 0.02
```

Synthetic data are generated by the code. IHDP experiments additionally require the external dataset described in [`data/README.md`](data/README.md).

## Reproducing the report

| Report item | Included artifacts |
|---|---|
| Figure 1 | `results/figure_data/figure1_rff_mf/` |
| Table 1 | `results/tables/table1_rff_synthetic/` |
| Table 2 | `results/tables/table2_rff_ihdp/` |
| Figure 2 | `results/figure_data/figure2_svgp_ihdp/` |
| Table 3 | `results/tables/table3_svgp_thresholds/` |
| Figure 3 | `results/figure_data/figure3_exact_svgp/` |

Regenerate the three report figures from the repository root:

```bash
python Code/plot_figure1_rff_mfvi.py
python Code/plot_figure2_svgp_ihdp.py
python Code/plot_figure3_gp_svgp.py
```

Each script reads the corresponding CSV files under `results/figure_data/`
and writes one PNG and one PDF to `results/figures/`.

Full Monte Carlo runs are computationally expensive. The small aggregate CSV files in `results/tables/` allow the published numbers to be checked without rerunning every replication.
